# Kronos Web Platform

Локальная веб-платформа на FastAPI + React для прогноза финансовых рынков на базе модели Kronos.

## Что входит

- Backend: FastAPI, SQLAlchemy, SQLite
- Frontend: React + TypeScript + Vite + TailwindCSS + Recharts
- AI-модель: Kronos из директории `D:\Kronos\model`
- JWT-аутентификация для демо-пользователя
- История прогнозов, избранные тикеры, бэктестинг

## Требования

- Python 3.11
- Node.js 18+
- npm
- интернет для загрузки котировок через Yahoo Finance или Coinbase Exchange (для BTC-USD и ETH-USD)

## Быстрый запуск

### 1. Подготовить виртуальное окружение Python

```powershell
cd D:\Kronos
python -V
D:\Kronos\venv\Scripts\python.exe -V
```

Если окружение отсутствует, создайте его:

```powershell
cd D:\Kronos
py -3.11 -m venv venv
```

### 2. Запустить backend

```powershell
cd D:\Kronos\webapp\backend
D:\Kronos\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

API доступно по адресам:

- Swagger: http://127.0.0.1:8001/docs
- Health: http://127.0.0.1:8001/health
- Котировка: GET http://127.0.0.1:8001/api/market/BTC-USD

Демо-пользователь:

- username: admin
- password: admin123

### 3. Запустить frontend

```powershell
cd D:\Kronos\webapp\frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

Frontend доступен по адресу:

- http://localhost:5173

## Команда для запуска всего проекта одним файлом

В корне репозитория есть `start.bat`:

```powershell
cd D:\Kronos
start.bat
```

Он запускает backend и frontend в отдельных окнах командной строки.

## Notes

- При сбое yfinance backend обращается к публичному Yahoo Finance Chart API напрямую; для BTC-USD и ETH-USD дополнительный резервный источник — реальные свечи Coinbase Exchange. Синтетические цены не используются.
- Для 4-часового таймфрейма Yahoo Finance-свечи агрегируются только из четырёх последовательных завершённых часовых интервалов; незавершённые свечи не участвуют ни в котировке, ни во входе Kronos.
- Цена в прогнозе — закрытие последней завершённой свечи, не биржевая цена в реальном времени. Интерфейс показывает время этой свечи и источник котировок; при недоступности источников API возвращает ошибку, а не тестовую цену.
- Dashboard обновляет выбранную котировку каждые пять минут через API и отдельно показывает время последней свечи и её источник. Доступные периоды соответствуют поддерживаемым Yahoo Finance: `1d`, `5d`, `1mo`, `3mo`, `6mo`, `1y`, `2y`, `5y`, `10y`, `ytd`, `max`.
- Backend использует закреплённые версии весов и токенизатора, проверенные регрессионными тестами Kronos. На вход подаются до 512 последних свечей, прогноз строится для выбранного таймфрейма.
- Каждый прогноз автоматически сохраняется в истории с исходной ценой, последней прогнозной ценой и временем целевой свечи. В разделе «Аналитика» приложение сравнивает его с первой доступной завершённой рыночной свечой на или после целевого времени.
- Для уже оценённых прогнозов показываются прогнозное и фактическое изменение от одной исходной цены, абсолютная ошибка в процентных пунктах и совпадение направления. Пока целевая свеча не закрылась, прогноз остаётся ожидающим; старые записи без сохранённых целевых данных не оцениваются задним числом.
- При открытии раздела «Аналитика» и по кнопке «Обновить фактические результаты» запускается проверка созревших прогнозов. Результат оценки сохраняется в SQLite и не заменяется прогнозной оценкой.
- Эти метрики описывают только сохранённые прогнозы и не являются гарантией будущей доходности. Выход Kronos не трактуется как калиброванная вероятность.
- Модель Kronos загружается один раз при старте backend и не копируется в webapp.
- База данных SQLite хранится в `D:\Kronos\webapp\backend\app.db`.
